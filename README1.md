## 🔧 前置准备

### 1. 获取美团的登录凭证

1. 浏览器打开 美团网站 [meituan.com](meituan.com) 并登录
2. 按 `F12` 打开开发者工具 → `Network`（网络）标签
3. 刷新页面，点击任意请求，查找 `Cookie` 或 `Authorization` 字段
4. 复制所需的值

> ⚠️ 凭证有效期有限，过期后需重新获取

---

## 📦 安装步骤

### 步骤一：下载脚本

将脚本文件 `mt_sign.js` 放入青龙面板的 `/ql/scripts/` 目录。

可以通过订阅管理自动拉取，或手动上传脚本文件。

### 步骤二：安装依赖

青龙面板 → **依赖管理** → **NodeJs** → 添加：

```
axios
```

### 步骤三：配置

首次运行脚本后，查看日志提示，根据提示配置所需的Cookie或环境变量。

### 步骤四：添加定时任务

青龙面板 → **定时任务** → **创建任务**：

```
名称：美团
命令：task mt_sign.js
定时规则：30 8 * * *（每天定时执行，可自行调整）
```

---

## 🔑 环境变量说明

本脚本无需配置环境变量，首次运行后按日志提示操作即可。

---

## ✅ 验证运行

执行任务后，查看日志应显示：

```
[美团] 签到成功
[美团] 任务完成
```

如果提示 Cookie 过期或认证失败，请重新获取Cookie/Token。

---

## ❓ 常见问题

**Q: 提示 "Cookie 已过期" 或登录失效？**
A: Cookie 有效期有限，重新登录获取新Cookie替换即可。

**Q: 依赖安装失败？**
A: 在青龙面板 → 依赖管理 → NodeJs 中手动添加。

**Q: 多账号如何配置？**
A: 同一环境变量添加多条值（每行一个），或配置文件中添加多个段落。
